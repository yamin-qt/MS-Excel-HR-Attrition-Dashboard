# 📊 HR Analysis Dashboard - Microsoft Excel

Transforming raw HR data into workforce insights using Excel Pivot Tables, dynamic charts, and interactive dashboard design.

---

## 📌 Project Overview

This project involved building a fully interactive **HR Analytics Dashboard in Microsoft Excel** — covering the complete data workflow from raw input to visual decision-support output.

Human Resources generates enormous amounts of data — headcount, attrition, department distribution, performance trends — but raw spreadsheets alone don't support decisions. This dashboard converts that data into a structured, visual format that HR managers and business leaders can use to **identify patterns, flag issues, and act quickly**.

## 🔢 How the Project Was Built

### Step 1 — Data Cleaning
Raw HR data rarely arrives clean. This step involved:
- Removing duplicate records
- Standardizing department names and job title formats
- Handling blank/null values in key columns
- Converting data types (dates, numbers, categories)
- Structuring data into a proper tabular format for Pivot Table compatibility

### Step 2 — Metric Definition
Identified the key HR metrics the dashboard needed to answer:
- Total headcount by department
- Attrition rate (overall and by department)
- Gender distribution
- Average tenure and age bands
- Performance rating distribution
- Active vs. inactive employee status

### Step 3 — Pivot Table Architecture
Built multiple Pivot Tables as the data engine behind each dashboard visual. Each Pivot Table was designed to update automatically when source data changes — making the dashboard reusable, not one-time.

### Step 4 — Dashboard Design
Designed a single-screen dashboard layout with:
- KPI summary cards (headcount, attrition %, avg tenure)
- Bar and column charts for department-level breakdowns
- Pie/donut charts for demographic distribution
- Slicers for filtering by department, gender, and year
- Color-coded indicators for at-a-glance status reading

## 💼 Real-World Applications

While built on a general HR dataset, this dashboard structure applies directly to:

- **Port and terminal HR management** — tracking operational staff, shift workers, crane operators
- **Logistics company workforce planning** — identifying high-attrition roles in warehouse or delivery operations
- **Shipping company HR reporting** — seafarer rotation tracking, shore-based staff analysis
- **Any organization needing headcount visibility** — the template is reusable across industries

---

## 📈 Decision-Making Value

An HR dashboard like this helps organizations:
- **Catch attrition before it becomes a crisis** — visible trend lines flag departments losing staff
- **Support recruitment prioritization** — headcount gaps visible by department and role
- **Back HR proposals with data** — budget requests, headcount approvals, training investments
- **Reduce reporting time** — what used to take hours in manual Excel work becomes instant with slicers

---

## 🔍 What Could Be Improved

- **Predictive attrition model** — add regression or scoring to flag employees at risk of leaving
- **Time-series trend analysis** — month-over-month headcount and attrition movement
- **Benchmarking layer** — compare internal metrics against industry attrition standards
- **Power BI migration** — rebuild for live data refresh, drill-through capability, and mobile access
- **Automated data input** — connect to HR system exports instead of manual data paste
